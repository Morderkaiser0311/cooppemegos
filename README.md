# Mego — Cooperativa de Ahorro y Crédito

Sitio web de demostración inspirado en la experiencia digital de Mego: landing con slider, canales electrónicos, productos, agencias, FAQ y accesos a MegoOnline / MegoEmpresas.

## Cómo ejecutarlo

```bash
npm install
npm run dev
```

Luego abre la URL que muestre Vite (por lo general `http://localhost:5173`).

## Scripts

- `npm run dev` — servidor de desarrollo
- `npm run build` — build de producción
- `npm run preview` — vista previa del build
